# 功能自知 0.1.0

独立的 AstrBot 插件；不替换人格，不调用模型，不自动发送消息或操作QQ空间。

## 开关与入口

AstrBot → 插件 → 功能自知 → 插件配置。可整体停用，或分别关闭能力摘要、动作记录、联系人查询。

- `get_function_awareness`：查询当前会话的实际工具名称、后台自动功能、关闭及不可用原因。
- `get_function_actions`：仅管理员私聊查询当前Bot、人格与你的私聊动作记录。
- `get_function_contacts`：仅管理员私聊分页查询 `friends`（QQ好友）或 `known_people`（明确归属的互动/记忆人物）。名单不等于完整历史；不返回其他人的聊天内容。

可自然询问“你能做什么”“你可以主动戳我吗”“你最近做了什么”“你有哪些QQ好友”“你记得认识哪些人”。模型是否使用工具仍由当轮判断；名单工具在群聊和非管理员请求中直接隐藏，函数执行时再次核对权限。

## 运行机制

请求末尾只保存当前请求引用，在 Agent 启动、内置工具补齐及已有权限过滤之后生成摘要。只读当轮工具集，不把全局注册状态当作调用权限。摘要以临时系统内容注入，不写入人设和聊天历史。

区分：本轮工具入口、后台自动能力、关闭、不支持、冷却、暂不可用、未验证。工具入口存在不保证网络、登录、额度及后端成功。对QQ空间的只读探测结果会按Bot/人格记住，失效后直到成功读取或探测才能恢复成功状态；摘要保留检查时间，不把旧检查当成实时保证。

兼容适配：AstrBot 4.29、Private Companion 6.7、Memory Companion 2.3。陪伴集成通过当前人格作用域读取，不修改上游源码。缺少可兼容接口时退化为当前工具集，不推断其他人格数据。

## 数据和边界

`data/plugin_data/astrbot_plugin_function_awareness/awareness.db` 独立保存，作用域为适配器实例ID、Bot身份、人格ID；动作再按会话隔离，保留7天。管理员可读取的近期陪伴动作、最新搜索/新闻记录及已确认的后台戳一戳时间会纳入观察。没有动机证据时明确写“动机未记录”，不凭人设补故事。

不存工具参数、结果正文、令牌或Cookie；好友和人物名单只读返回，不自动存入长期记忆。记忆人物只取明确归属当前Bot/人格的记录及当前适配器的互动档案；无法确定归属的旧记录不混入，名单明确标注可能不完整。

独立的认证管理接口（使用 AstrBot 自身插件权限）：

- GET `/api/v1/plugins/extensions/astrbot_plugin_function_awareness/status?umo=<管理员私聊UMO>`：后台状态和上一次真实请求快照。没有真实请求时不伪造可调用工具。
- POST 同前缀 `/probe`：JSON `{"umo":"适配器:FriendMessage:管理员ID","kind":"qzone"}`；kind仅允许 qzone、friends、known_people。只读，不发布、点赞、评论或发送QQ消息。

关闭或卸载保留独立数据文件；重装后可继续使用。删除本插件不会更改AstrBot人格、陪伴或记忆插件数据。

本版本进行了源码语法检查及安装/只读接口检查；没有额外添加或运行测试套件，也没有自动发送QQ测试消息或额外模型推理。
