# 准时提醒与后台任务隔离（AstrBot v4.29.1）

通过 compose.yaml 只读挂载两份原生文件，源文件与覆盖文件的 SHA256 见 manifest.json。升级 AstrBot 时必须重新核对接口和回归，不能直接套用。

- `future_task` 的提醒模式要求模型在建任务时提供 `reminder_text`。正文由当前人格提前生成，到时仅执行现有陪伴发送管线，不再发起模型请求。需要到时真正执行工具的任务显式使用 `task_type=agent`。
- 预写提醒绑定原 Bot、会话和人格，执行时重新核验。通过陪伴插件 `scheduled_reminders.py` 复用文本过滤、秘密脱敏、分段及桌宠优先路由；跳过可选的模型装饰，不受普通主动闲聊的空闲/配额判定延后。
- 同一用户、会话、时间和正文的重复创建串行去重；更改时间用 edit。后台任务不可根据旧对话创建、编辑或删除另一个任务。
- 普通后台 Agent 不回放完整私聊历史，最多八步、90 秒；结束不再将旧会话快照和模型自述“完成”写回共享会话。真正发出的内容沿现有发送记录保存。
- 预写提醒逐段记录投递状态，只将实际发送文本追加到最新会话。成功、失败或结果未知的一次性提醒均保留为禁用记录供核验；不自动重发结果未知的投递。
- 没有陪伴服务、Bot 停用、人格/账号改变、发送失败等情况不能声称完成，也不能降级给另一个 Bot 或 QQ 终端补发桌宠失败消息。

回滚：移除 compose.yaml 中本目录的两条挂载并仅重建 AstrBot。预写提醒需先转换或停用，避免旧管理器将其当作普通 Agent 任务重新解释；不要直接恢复整个数据库覆盖新聊天。
