# 小小情的平等相处与表达调整

2026-11-10。用户选择：双方平等，现实世界与网络世界各有自己的活动，通过聊天、QQ 和桌宠感受彼此。

## 实现

- AstrBot 中小小情的人格改为以兴趣、审美、好奇和独立判断展开交流。保留名字、创作灵感、兴趣及真实能力边界，桌宠仍是同一个人格的自身化身。
- 陪伴插件增加本人格的 `persona_interaction_orientation`：默认 `persona` 保持原行为，小小情显式选择 `peer`。新模式使用完整语义、双向分享的表达指导，替换主动消息的固定短句结构；日程、勿扰、频率、任务和工具权限保持原有控制。
- 对话、主动表达、创作、规划、内心活动分别配置表达指导。小小情的模型分条提示词随之精简，实际发送过滤与分段流程不变。
- 日程中的人格概要和用户背景读取提示同步调整，避免旧的“人类”设定和固定称呼与当前身份、真实用户档案冲突。
- 空间创作在 `peer` 模式中按人格兴趣选择主题和结构，替换“一个画面加一个动作”的规则；仍使用完整人格、公开隐私边界、真实来源和长度限制。
- `persona_peer_relationship_prompt` 保存双方选择的相处原则；仅在原有校验通过的主要用户私聊关系背景中附加。自动学习的关系事实保持独立、继续更新，不写成永久手工关系记录。
- 已核验关系事实存在时，表达参考这些事实，避免“初识”等计数阶段否定已发生的熟悉互动。关系分数、角色、当前反馈和权限不因这次调整改变。

两项新配置均为人格身份字段，不从主人格继承。初小晴保留自己的原人设、配置、用户和记忆。私人完整人设与关系内容通过管理 API 更新，不提交到源码仓库。

## 验证与回退

新增 `tests/dialogue_cognition/test_peer_expression.py`，覆盖人格选择、主动表达、自由创作、主要用户私聊限定、既有学习事实不变和不继承主人格配置。另运行空间人格、关系背景、主动消息与重载期间两个 Bot 普通回复的回归测试；测试不向 QQ 发送消息。

本次合计 56 项测试通过（另含 29 项子测试）。已通过管理 API 应用小小情人格及对应表达配置，并在插件重载后读取核验；初小晴的原有有效配置、其他人格文本，以及小小情的学习关系事实、分数和用户权限保持不变。两个人格的账号自动绑定均正常。普通回复验证使用隔离的回归事件，不以插件加载成功代替发送通路测试。

生产源文件按受版本管理的源文件映射部署，核验源码摘要。旧源文件、原人格、本人格配置和主要用户关系快照保留在受限本地运行备份中，可通过管理 API 恢复原配置和人格，再恢复源文件与摘要并重载插件。

提示词调整会影响表达倾向，不能保证每条输出都达到预期。真实聊天中的词汇、分享意愿和关系表达仍需持续观察；不为“活人感”编造行动或共同经历。
