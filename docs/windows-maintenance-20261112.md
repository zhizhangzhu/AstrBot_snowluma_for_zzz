# scripts/windows/Connect-AstrBotMaintenance.ps1：命令隔离与超时

临时维护通道依旧由用户在 Windows 手动启动，只以当前用户身份执行，通过已有 SSH 回连 Linux。关闭窗口即可终止维护，不安装常驻入口。

旧代理在 `[PowerShell]::Create()` 的内部运行区中执行命令，并在超时后调用 `Stop()`。此次读取文件/网络连接和外部 SCP 命令出现未确认结果，运行区的停止也未及时返回，后续命令因此无法接收。未确认期间没有替换客户端文件。

新代理为每次命令创建独立 PowerShell 子进程，通过临时 UTF-8 BOM 脚本文件传入命令，避免 Windows 命令行长度限制和 PowerShell 5.1 对中文编码的误读。子进程为非交互模式，标准输入关闭，标准输出与错误异步读取；超时仅请求终止该命令的进程树，维护 SSH 继续运行。超时返回“未知”，不能把它当作操作未发生，应先核对现场再决定是否重试。

客户端更新须先核对旧文件摘要、校验更新包，再备份加密配对、配置、旧程序文件及模板。回滚检查更新后文件是否被再次改动，不覆盖后续人工编辑。保留安装记录和运行依赖，不使用 NSIS 临时安装目录验收。

实际验证及更新情况记录在 `.runtime/terminal-prompts-20261112/acceptance.json`。文档完成或 Linux 侧校验不代表 Windows 子进程超时恢复已验证。
