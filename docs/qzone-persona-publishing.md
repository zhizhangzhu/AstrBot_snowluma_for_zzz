# qzone_publish.py / qzone_schedule.py：QQ 空间写作与人格

生活说说的任务正文包含：

```text
请以当前 Bot 人格写一条 QQ 空间说说。
只输出说说正文，不要解释，不要加标题。

要求：
- 遵守本次日程选择的字数范围和硬上限。
- 像自然生活动态，不是公告、不是任务汇报。
- 开头直接进入一个具体画面或动作，不要总结式开场。
- 可以带一点公开可见的心情、天气或日记余味，但不要暴露插件、模型、内部状态数值。
- 禁止出现“能量”“心理能量”“/100”“状态变量”“当前状态”等内部汇报词。
- 不要 @ 用户，不要泄露私聊内容，不要写得像营销文。
- 写作角度：本轮选择的具体生活片段。
```

随后拼接当前人格的说说风格、创作表达风格、时间与季节、可公开状态、当前或附近日程、日记与记忆中可公开的参考、近期已发内容去重、关系事实边界与世界观适配。情绪说说使用独立任务，通常要求 20–80 字，只写模糊心情，不披露具体用户或私聊。

共用的默认风格是：随手生活碎片、具体画面与动作、口语、短、轻；避免哲理总结、人生感悟、诗化独白、营销文案、谜语与模板开场。自定义风格与创作表达设置按人格读取。

`qzone_persona.call` 另外将当前明确选中人格的完整 AstrBot 人格作为系统提示词传入。初稿、情绪动态、字数改写、去重、净化及配图提示生成都经过此入口。查不到该人格、人格为空或等待期间作用域改变时终止生成，不回退到其他默认人格。公开素材边界附加在系统提示词中；完整人格中的私人关系和内部设定不因此成为公开素材。
