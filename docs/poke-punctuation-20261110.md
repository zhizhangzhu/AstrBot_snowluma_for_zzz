# 戳一戳回复句尾句号（2026-11-10）

## 原因

10:33 的小小情戳一戳回复、反戳回复均有句尾句号。普通私聊的最终响应和主动消息已有 `_strip_terminal_sentence_period` 处理；`reactive_poke_context.send_reply` 独立生成、直接发送，清理控制标记后没有经过该处理。这是发送分支遗漏，并非网络问题或用户画像丢失。

## 修改

在戳一戳统一发送入口复用现有句尾规则，覆盖 reaction 与 poke_back。先清理控制标记和句尾句号，再选择表情、发送和记录会话，保证认知记录与实际发送一致。不修改人格、用户设置、历史消息或群聊权限。不增加模型调用。保留问号、感叹号、省略号及句中标点，沿用普通聊天既有规则。

## 验证

`tests/dialogue_cognition/test_poke_punctuation.py` 覆盖两个 Bot、两种戳一戳回复，以及中文/英文句尾句号、引号、问号、感叹号、省略号；检查表情选择输入、发送正文和持久化正文一致。另运行已有戳一戳上下文、表情桥接与跨热重载普通回复测试。测试使用实际 AstrBot 镜像且禁止网络，不向 QQ 发送测试消息。

仅更新并重载陪伴插件，保留私有源码与清单回滚副本；后续真实 QQ 投递以用户实际聊天核验。

结果：24 项新增回归、60 项现有回归通过。现有 `test_poke_turn_continuity.Owner` 的 Context 替身原缺少 `get_all_stars`，导致两项主动戳一戳测试在进入本次修改代码前失败；补上 `get_all_stars=lambda: []`（模拟未接入桌宠）后全组通过。该运行目录测试文件不在源码基线内，重建旧测试夹具时需保留此修正。
