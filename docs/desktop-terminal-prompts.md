# core/astrbot/prompts.ts：桌宠身体、能力与提示词展示

AstrBot 负责小小情的人格、记忆与思考。桌宠客户端提供当前身体、可用工具和真实互动；它的提示词是环境说明，不另设一套人格。

桌宠模板：

- 中文：`Coopanion/core/astrbot/prompts/desktop-pet.zh.md`
- 当前模型使用的英文版：`Coopanion/core/astrbot/prompts/desktop-pet.en.md`

兼容控制台模板：

- 中文：`Coopanion/core/astrbot/prompts/console.zh.md`
- 英文：`Coopanion/core/astrbot/prompts/console.en.md`

## 当前形象与自主动作

形象包的 `about` 与当前装扮选项组成 `pet.body`：银白发、遮住一眼的侧刘海、浅灰紫瞳、白黄青配色裙装、深灰裤袜、白色短靴、向日葵/太阳帽及独立星饰。坐凳伙伴叫小垃圾（gomidasu）。头饰选择以当前客户端状态为准，不把所有可选头饰都描述成正在佩戴。

小小情可按人格、意愿与情境主动选择实际支持的表情、移动、动作、坐下、睡觉、换装、气泡与提问；可查询已启用 World 和扩展并调用真实工具。能力发现使用 `desktop_pet_capabilities`，执行使用 `desktop_pet_call`；分页查询完整工具参数。键鼠、录屏等能力继续遵守实际可用性和原生授权，拒绝、取消、锁屏、休眠与离线不能被提示词绕过。

当前外观还作为简短 `appearance` 上报，普通消息与精简触摸上下文都保留，避免为了降低触摸延迟而丢失身体认知。旧客户端未上报该字段时保留兼容，普通环境说明仍可查询。

## “未纳入当前前缀”

该标记原本只检查客户端本地 `systemSegments` 是否包含模板的来源键。AstrBot 模式原来只返回 AstrBot 人格段，桌宠环境却另经能力目录发往服务器，因此本地界面会把有效的桌宠模板显示为未纳入。

现在客户端前缀预览包含它上报的环境模板，并保留相同来源键。部署目录中用户编辑的覆盖文件同时用于目录上报和前缀预览；覆盖文件优先于内置模板，升级不自动覆盖人工编辑。

此预览不代表服务器最终请求的完整转储：实际请求还由 AstrBot 加入记忆、最近对话、时间与插件上下文。服务端日常上下文会缩短环境说明，完整工具约定可以按需查询。

## “控制台对话”的用途

这是原 Cortico 客户端的可选 Console World，可用于本地组装时的独立控制台输入与输出。它与当前日常聊天用的桌宠对话页不同，不能用来修改 AstrBot 人格。

AstrBot 终端的能力目录不包含该兼容 World，因此它的模板继续显示未纳入，不影响桌宠聊天。来源 PIN 只确认控制台来源，不授予额外权限。

## 保存、应用与回滚

模板编辑保存后，下次目录刷新会发送给 AstrBot；连接正常时最迟在下一次约 30 秒目录刷新中更新。客户端当前预览可点“立即应用”刷新。已存在的人工覆盖不会被新的内置模板替换；本次维护需先备份，再按用户要求替换这两份覆盖。

Windows 更新先备份程序源文件、两份模板覆盖和客户端配置。只更新对应客户端及本设备数据，不清空共享聊天、配对或其他 Bot。离线中文/英文模板可供人工审阅；未接通维护通道时不得将源码提交描述为已更新运行客户端。

## 形象图片输入

形象包可用 `portraits` 声明按预设选择的静态 PNG。小小情的六种头饰/星饰组合来自同一真实绘制器，384×413、每张约 100–112 KB；仅传当前选择，不截取用户桌面或聊天。客户端缓存当前素材，变更装扮/素材版本会更新图像摘要。未声明图片的旧形象包继续只提供文字，不拿近似缩略图冒充当前装扮。

WSS 目录传递当前图片的 PNG 字节、摘要、尺寸和装扮信息。服务器校验格式、摘要和尺寸，复用已验证素材。普通上下文与精简触摸上下文只显示图像元数据；大段 base64 不混入提示词 JSON 或能力查询结果。图片通过 AstrBot 的 `TextPart` / `ImageURLPart` 作为额外视觉内容进入模型请求，原用户文字、图片与会话身份保持不变。

同一请求重复进入钩子会替换已有的受管参考，不堆叠图片；已有上下文中实际存在同一图片时复用，只有文字回忆时仍提供真实图片。换装后当前图覆盖请求中旧的受管参考，不把旧外观当成现在。图片不会单独触发模型生成，也不额外调用一次识图模型；它属于正常多模态请求，仍会消耗所用模型的图片输入额度。

形象图片是外观参考，不证明动作成功、当前表情或屏幕内容，也不授予键鼠与录屏权限。Windows 尚未部署新目录上报代码时，服务器不会谎称收到了形象图片。
