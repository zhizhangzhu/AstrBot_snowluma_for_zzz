## 改动

提醒正文在创建时由人格模型写好，准点只走经过验证的过滤/分段、桌宠或QQ路由；不在时间点串行等待网络模型。绑定与发送结果必须核实，完成与失败留在任务记录中。实际投递才追加聊天，失败、部分或结果未知不自动重发。

普通 Agent 的后台上下文和实时聊天隔离；禁止从后台旧对话衍生其他提醒，后台运行限时；不将模型完成自述当作回执。重复创建同一时间、会话、正文的提醒复用既有任务。

自主开发反馈支持“后台看一看/逻辑问题/自行修复”等表达；聊天任务查询返回有界的状态、暂停原因和下一步。增加 `replan(task_id)`，只允许对因基线变化且尚未实施的旧方案重新规划，撤销旧审批并重新走阶段审批；人工暂停、已有工程产物和开发关闭状态不允许借此恢复。原面板恢复同类任务也走重规划，不再重试过期方案。
