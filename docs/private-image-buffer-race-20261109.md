# 私聊单图缓冲并发异常（2026-11-09）

## 现象与原因

11:19:34，陪伴插件 `on_private_message` 在单图处理分支写入 `buffers[key]["images"]` 时抛出 `KeyError`，框架将内部异常发进了聊天。它不是 QQ 空间连接超时造成的；同一时段另有空间网络错误，两者应分别诊断。

原代码先发布单图占位缓冲，再临时释放人格数据锁保存图片。存储期间其他消息收口、过期清理或同会话处理可以取走/替换该条目。原协程重新取得锁后仍假定条目存在，导致异常；即使条目已被替换而没有报错，也可能将图片写进另一代缓冲。

## 修复

在 `message_pipeline._prepare_private_image_buffer` 中先完成可等待的图片持久化，再取得当前缓冲并发布占位。随后在持锁、无等待的区间填写图片、原事件和视觉任务。没有图片或没有可用缓冲时放行原始事件，不删除同时到达的文字缓冲。禁止用简单 `setdefault` 恢复旧条目，因为这可能掩盖已被消费的旧一代状态。

本次仅修改单图入口，不修改空间网络配置或说说提示词。
