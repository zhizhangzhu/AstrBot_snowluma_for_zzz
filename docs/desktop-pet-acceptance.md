## 后续提出的界面和故障修复

| 项目 | 结果 |

| 普通消息未送达 | 修复 AstrBot 人格返回值兼容，以及普通入口中的未定义变量；实机普通输入成功触发小小情桌宠回复。 |
| 工具调用失败 | 公开参数 tool 与 AstrBot 调度器保留参数冲突，改为 capability；实际 FunctionToolExecutor 回归和实机 pet_say 通过。 |
| 共享记录遗漏工具问话 | 仅投影已确认展示的 say / ask 正文，排除未确认动作、推理及私有工具结果；实机查询通过。 |

| 桌宠被说成“我的屏幕鲸鱼” | 新增明确的身体认知：形象是同一人格的自身化身，换皮不换身份；应以第一人称理解触摸，不是另一个宠物。模型后续用语还需观察。 |
| 表情包串到 QQ | 表情插件把 desktop_pet 加入 event.send 路径；成功和断连两种回归均确认不调用 QQ 会话发送接口。 |

## 还需要人工体验的项目

1. 从 QQ 继续桌宠刚聊过的话题，再切回桌宠，观察记忆、称呼和回复目标。
2. 桌宠摸头 / 戳动后检查自然回应、表情图片展示和身体用语；换装不应每次都生成一条回复。
3. 观察一次自然主动互动、完整日程和日记，核对没有重复 QQ 打扰或虚构执行。
4. 对实际需要的扩展逐个核验权限、配置和功能；语音、桌面感知、电脑操作没有自动等同于全部授权。

以上不是阻止继续使用的审批步骤。当前版本可以使用，但未完成的体验验收、复杂扩展适配、完整历史归档、自动更新和正式签名发布不能标成已经完成。
