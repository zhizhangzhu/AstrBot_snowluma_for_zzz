## 电脑操作与图片气泡增量

服务端已部署 **0.2.5**，用户 Windows 当前已安装 **0.3.5**。正式小小情实例实际申请授权后，Shift 按下 / 松开均有回执；可见计数为各 1 次，鼠标约 40 像素移动也有回执。Bot 没有执行复位却曾声称已复位，维护操作已恢复原坐标，记录保留并补充逐步核对要求。原 CUA 配置恢复为关闭、ask-once / 30 分钟。详情见[电脑操作记录](desktop-computer-use-20261103.md)。

0.3.5 修复纯图片气泡的空白文字行，并修正连续动作间的能力目录发布顺序。客户端 520 项、World 204 项通过，3 项跳过，三项类型检查和构建通过；[Windows 构建和安装验收](https://github.com/zhizhangzhu/Coopanion/actions/runs/41580687347)及[普通 CI](https://github.com/zhizhangzhu/Coopanion/actions/runs/41580687306)均通过，包含紧接前次回复的纯图片展示回执。前一候选的失败结果保留，不算交付成功。

最终源码 `Coopanion@3617b73f62f92b12febc1fc73b6e68b8fbf1453b`；[Windows x64 安装包](https://github.com/zhizhangzhu/Coopanion/actions/runs/41580687347/artifacts/13205792138)的 ZIP SHA-256 为 `aa418669741de2bf5ce200efa2cfc4e50b863813e1f1915d62b9e6fc4346d020`，在用户电脑重组下载后核验一致。实机再次读取版本 0.3.5、正式 WSS 在线、小小情 / 猪猪、原加密配对不变、纯图修复存在、调试端口关闭、CUA 仍关闭。当前真实锁屏，未在锁屏状态继续键鼠输入。后台安装核对脚本已结束；旧白色测试实例及测试设备此前已清理。

本轮结束时已关闭临时 Windows 维护连接，删除该会话的临时凭据和套接字；正式桌宠使用自己的 WSS 连接，不依赖维护窗口。
